# 2026-11-10 项目检查与修复

检查范围：配置与启动、QQ 接线、消息投递预算、LLM 流式与工具循环、联网工具、语音合成与投递、状态与会话保存、长期记忆和交付脚本。

## 已修复

| 问题 | 结果 | 文件 |
|---|---|---|
| 主动聊天定时器位于 `await bot.start()` 后；SDK 的该方法在连接结束时才返回 | 改由 `ready/resumed` 事件在确认上线后启动定时器 | `src/bot.js`、`src/index.js` |
| LLM 使用错误的顶层 `effort`，各服务请求格式混用 | DeepSeek 发 `reasoning_effort`；OpenRouter 发 `reasoning`；保留按请求覆盖思考开关 | `src/llm.js` |
| 任意包含 effort 等词的 HTTP 错误都可能触发重试，并清空全局配置 | 只处理明确的未知参数错误，按模型和具体字段隔离；具体档位被拒、认证、余额和服务器错误不自动换配置；关闭推理不退回服务默认 | `src/llm.js` |
| 推理模型工具续聊丢失推理文本或签名块 | 累积 SSE 推理片段，在工具调用后的 assistant 消息中原样保留；识别 choice 内嵌错误 | `src/llm.js`、`src/conversation.js` |
| 模型返回未提供的工具名也会执行 | 每轮执行前检查工具是否存在于本轮定义清单 | `src/conversation.js` |
| 切服务后可能误用 DeepSeek 的 key、默认视觉型号；显式空视觉型号未生效 | 按服务选专用 key，显式通用 key 优先；空视觉型号关闭识图；中转可用 `LLM_PROVIDER` 指定协议 | `src/config.js` |
| `/effort auto` 不被接受，重启也没有恢复分支；部分服务默认状态显示不准 | 补齐 auto 设置和恢复，扩展兼容服务的候选档位；默认未知档位显示 auto | `src/commands.js`、`src/index.js` |
| 联网工具丢弃取消信号，DNS 阶段不在超时内 | 信号贯穿工具、DNS、重定向和正文读取；新消息能中断联网工作 | `src/tools.js`、`src/web.js` |
| IPv6 / IPv4 映射地址和重定向可绕过内网检查；独立 DNS 检查后还会再次解析 | 验证每个重定向目标，将验证后的地址绑定到实际连接；正常 fc/fd 开头域名不再被误拦 | `src/web.js` |
| 网页读取超过上限仍可能继续下载，压缩内容缺少展开后上限 | 限制响应与解压后的字节数，读取结束或失败时关闭流 | `src/web.js` |
| 长语音退回文件后返回字符串，被误判为零次语音投递 | 返回成功投递数量，文件成功后不再重复补全文 | `src/delivery.js`、`src/conversation.js` |
| 分段语音部分失败时漏掉该段；全部失败时可能重复贴两次文本 | 只补发未朗读段落；全失败只回一次全文；保留工具语音失败标记以避免再次合成 | `src/conversation.js` |
| 先发出部分语音再失败时，整文件回退重复已发送部分；两条长语音路径逻辑分叉 | 文件只包含剩余音频；普通长回复与 `/long` 共用投递逻辑、预算和临时文件清理 | `src/delivery.js`、`src/commands.js` |
| 非法 WAV 元数据进入后续处理，PCM 与其他编码也可能混拼 | 提前校验关键格式，限制 PCM 变换并拒绝混合编码拼接 | `src/audio.js` |
| Altare 手动解析 TZ 不支持引号和行内注释，日志时区未使用配置 | 使用 dotenv 解析器；配置验证通过后使用设置的时区；无效地址不会在验证前写入日志 | `altare.js`、`src/index.js` |

## 交付

`dist/xiaoyan-qqbot-altare.zip` 包含最新源代码、测试和说明。压缩包不包含真实 `.env`、运行时 `data/`、`node_modules/` 或旧压缩包；更新服务器程序文件时保留现有 `.env` 与 `data/`。

OpenRouter 的运行时参数格式已适配，但尚未自动按元数据生成动态菜单，也没有逐个模型进行在线验收。切换前仍应使用 `scripts/probe-model.mjs` 查询其实际能力。
