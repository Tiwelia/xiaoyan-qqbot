# 聊天操作体验调整（2026-11-10）

本次优先减少日常操作的指令负担，只涉及本地设置和反馈，不改角色本体。

## 直接说就能操作

| 场景 | 发给机器人的话 |
|---|---|
| 持续改用文字 | 关闭语音 / 以后只发文字 |
| 恢复语音回复 | 打开语音 / 恢复语音 |
| 看当前设置 | 查看设置 |
| 看维护详情 | 查看详细状态 |
| 找一个声音 | 找音色 灵心 |
| 按已知名字换音色 | 音色换成龙安灵心 |
| 浏览音色 | 查看音色 / 查看音色第2页 |
| 忘了怎么操作 | 查看帮助 |

开关是明确设值，重复发「打开语音」不会再关闭；开关和选中的音色沿用原有状态文件持久化。换音色仍会开启语音。设置操作不调用模型，回执使用原有投递预算。

仅识别独立、明确的语句。引用、问句、夹带正文、附图，以及「这条用文字回」不会修改持久设置。自然语言换音色只识别实际清单里的名称或 ID；未知名称仍可通过 `/voice 名称` 得到查找提示。删除记忆和清空会话继续使用明确指令。

## 清单和状态

- 音色从一次列出八十多个改为每页 10 个，优先显示复刻音色，用名称显示并标记当前选择，每项保留可复制的切换指令。
- 按名称、ID、语言、性别、系统/复刻筛选；搜索结果超过 10 个时提示缩小关键词，全部音色仍可分页浏览。
- `/status` 和「查看设置」默认只给日常需要的模型、思考档位、回复方式、音色和主动聊天状态；记忆库不可用仍显式提示。
- 并发、缓存、临时文件等维护数据移到 `/status detail`，原有数据没有移除。
- `/help` 改为日常说法示例；完整指令移到 `/help all`。原有指令均保留。

## 验证范围

新增离线消息场景回归，覆盖重复开关、状态重载、误识别、权限、禁用指令、音色搜索与分页、中文/英文复刻名称，以及真实消息流水线中一次文字回执且不调用模型。

不连接真实 QQ、不调用模型或 TTS 服务；本次验证不代表线上消息和语音已验收。
